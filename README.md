# 📌 Project Overview

**ShopEase** is a Java Full Stack E-Commerce Application developed during my Java Full Stack Development Internship at JSPIDERS.

The application provides a complete online shopping platform where customers can browse products, manage carts, place orders, and merchants can manage products efficiently through dedicated dashboards.

The system follows a layered architecture using Java, JDBC, MySQL, HTML, CSS, and JavaScript.

# 🔄 Application Workflow

1. Customer registers and logs in.
2. Customer browses available products.
3. Products are added to cart.
4. Customer places order.
5. Payment is processed.
6. Order is confirmed.
7. Merchant manages products.
8. Admin monitors overall system activities.
